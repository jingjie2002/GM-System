# 🚀 游戏 GM 后台管理系统 (GM-System)

一款基于 **Django 5.0** 与 **Vue 3** 开发的现代化、响应式游戏后台管理系统。系统专注于高效的运营操作流，提供玩家管理、公告发布、全服补偿、礼包码批量生成及严密的系统审计功能。

---

## 📋 功能模块

### 1. 仪表盘 (Dashboard)
- **全局概览**：实时统计玩家总数、生效中的公告数量以及 CDK 库存。
- **动态追踪**：自动获取最近 5 名注册玩家的详细信息（等级、金币、状态等）。
- **极速入口**：一键跳转核心业务模块，优化操作路径。

### 2. 公告管理 (Notice Management)
- **多类型支持**：支持登录公告、滚动公告和系统通知。
- **定时任务**：支持设置公告生效的起始与结束时间。
- **状态流转**：提供“草稿”与“已发布”两种状态，确保内容发布严谨。

### 3. 邮件系统 (Mail Management)
- **精准发放**：支持通过玩家 UUID 发送一对一私信或奖励。
- **全服广播**：支持一键向全服玩家发送系统邮件或节日补偿。
- **道具附件**：支持随信附带游戏金币等虚拟道具，并实时追踪领取状态。

### 4. 礼包码管理 (CDK Management)
- **批量生成**：支持一键生成上百个高强度随机兑换码。
- **灵活配置**：
  - **单次码**：一码一用。
  - **通用码**：支持多人共用同一口令（如节日福利）。
- **生命周期**：支持自定义过期时间，过期后自动失效。

### 5. 系统审计 (Audit Logging)
- **行为追踪**：实时记录管理员的所有增、删、改、封等关键操作。
- **安全取证**：记录操作时间、操作人 IP、目标对象及详细的变更内容。
- **防篡改展示**：日志仅供查询，作为系统安全审计的最高优先级依据。

### 6. 个人中心 (Profile)
- **身份识别**：实时展示当前管理员的权限等级（超级管理员/普通管理员）及注册时间。
- **安全防护**：提供便捷的自主修改密码功能。

## 🛠 技术架构

### 后端 (Backend)
- **Core**: Python 3.12 + Django 5.0
- **API**: Django REST Framework (DRF)
- **Security**: SimpleJWT (Token 认证机制)
- **Architecture**: 
  - **AuditLogMixin**: 自动化操作日志采集。
  - **UnifiedResponseRenderer**: 规范化 API 响应结构，确保前后端对接零成本。

### 前端 (Frontend)
- **Framework**: Vue 3 (Composition API) + Vite
- **Styles**: Tailwind CSS (原子化 CSS 方案)
- **Icons**: Phosphor Icons (双色艺术风格)
- **Network**: Axios (封装请求拦截与异常处理)

## ✨ UI 优化特性 (最新版)

- **视野优化**：移除了表格顶部的固定吸顶（Sticky）效果，表头随内容自然滑动，增大有效可视区域。
- **沉浸式交互**：去除了繁琐的翻页按钮，改为更直观的纵向滚动加载模式。
- **精致布局**：将数据总量（共 XX 条）移至标题栏旁侧，保持界面底部极致清爽。
- **空值保护**：针对所有字段做了前端空值防御（Optional Chaining），彻底杜绝因后端脏数据导致的页面崩溃。
- **赛博风格**：基于毛玻璃效果（Backdrop Blur）与深蓝色调，打造科幻感的 GM 操作终端。

## 🚀 快速启动

### 1. 后端环境
```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 数据库迁移
python manage.py migrate
```

### 2. 前端环境
```bash
# 进入前端目录
cd frontend/gm-system-vue

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```
### 🔗 开发标准
**接口地址：/api/**

**认证方式：Authorization: Bearer <token>**

**数据规范：所有接口均返回 code, message, data 三大核心字段。**

# 启动服务
python manage.py runserver
